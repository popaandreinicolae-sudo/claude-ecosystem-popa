# Șabloane de documente diplomatice

Structuri de lucru. Adaptează registrul la destinatar și la nivelul de clasificare.
Nu completa cu date inventate; lasă câmpurile între paranteze drepte.

## [nota-verbala] Notă verbală
Comunicare oficială la persoana a treia, între misiuni sau între misiune și MAE.

```
Ambasada [statului expeditor] prezintă salutul său [Ministerului / Ambasadei ...]
și are onoarea de a [comunica / solicita / confirma] următoarele:

[corpul comunicării, persoana a treia, o singură idee per paragraf]

Ambasada [...] folosește acest prilej pentru a reînnoi [Ministerului / Ambasadei]
asigurarea înaltei sale considerații.

[Localitatea], [data]
[Sigiliu]
```

## [telegrama] Telegramă diplomatică (proiect)
Instrumentul de raportare și de instrucțiuni între Centrală și misiuni.

```
CLASIFICARE: [nesecret / secret de serviciu / ...]
PRIORITATE: [normală / urgentă / foarte urgentă]
DE LA: [misiune / direcție]      CĂTRE: [direcție / misiune]
REF: [telegrame / documente anterioare]
SUBIECT: [titlu scurt, concret]

1. [Faptul principal, esența, în prima frază.]
2. [Context și detalii relevante.]
3. [Pozițiile actorilor, reacții, nuanțe.]

CONCLUZII ȘI PROPUNERI:
- [evaluare proprie]
- [propuneri de acțiune sau de instrucțiuni solicitate]
```

## [fisa-dosar] Fișă de dosar
Pentru pregătirea unei reuniuni sau a unei poziții (de tip COREPER/Consiliu).

```
DOSAR: [denumire]
STADIU: [unde se află procedura]
MIZA: [de ce contează pentru România]
POZIȚIA ROMÂNIEI: [linia agreată, marja de manevră]
POZIȚIILE ALTOR STATE MEMBRE / INSTITUȚII: [aliați, opozanți, indeciși]
PUNCTE DE ATENȚIE: [linii roșii, sensibilități]
RECOMANDARE: [ce susținem, cum, cu ce argumente]
```

## [elemente-de-limbaj] Elemente de limbaj
Puncte scurte, defendabile, pentru intervenții și convorbiri.

```
MESAJE PRINCIPALE:
- [punct 1, o frază, susținut cu o sursă sau o cifră verificată]
- [punct 2]
- [punct 3]

LINII DE APĂRARE (dacă se insistă):
- [răspuns la obiecția probabilă]

ÎNTREBĂRI SENSIBILE ȘI RĂSPUNSURI:
- Î: [...]  R: [...]
```

## [non-paper] Non-paper
Document informal, fără antet și fără atribuire, pentru a testa o poziție.

```
[Titlu neutru]

[Expunere concisă a problemei și a poziției, ton sobru, fără formule oficiale.
Se folosește pentru a împărtăși o perspectivă fără a angaja formal statul.]
```

## [raport-misiune] Raport de misiune / notă de informare către Centrală
```
SUBIECT: [eveniment / întâlnire / dosar]
DATA ȘI LOCUL: [...]
PARTICIPANȚI: [...]

1. CONTEXT: [de ce a avut loc]
2. DESFĂȘURARE: [ce s-a discutat, esențial]
3. EVALUARE: [semnificație pentru interesele României]
4. PROPUNERI / PAȘI URMĂTORI: [follow-up concret]
```

## [fisa-tara] Fișă de țară (serviciu exterior)
```
STAT: [...]
RELAȚIA BILATERALĂ: [stadiu, cadru juridic, vizite recente]
INTERESE ROMÂNEȘTI: [politic, economic, energetic, cultural]
OPORTUNITĂȚI: [investiții în ambele sensuri, cooperare sectorială]
RECOMANDĂRI DE PROMOVARE: [pași operaționali]
```
